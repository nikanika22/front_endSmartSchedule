# Import từng sequence diagram vào draw.io

Mỗi file `.mmd` trong thư mục này chứa đúng một sơ đồ Mermaid và đã bỏ
`autonumber`, nên các thông điệp sẽ không còn số `1, 2, 3, ...`.

## Cách nhập

1. Mở draw.io/diagrams.net và tạo một diagram trống.
2. Chọn **Arrange → Insert → Mermaid**. Một số giao diện đặt mục này trong
   **Arrange → Insert → Advanced → Mermaid**.
3. Mở một file `.mmd`, sao chép toàn bộ nội dung rồi dán vào hộp Mermaid.
4. Chọn kiểu **Diagram** để chuyển thành các shape draw.io có thể chỉnh sửa.
5. Bấm **Insert**.
6. Tạo một page mới trong draw.io rồi lặp lại với file tiếp theo.

Nếu muốn giữ Mermaid để sửa lại bằng code, chọn kiểu **Image**. Khi đó draw.io
chèn một SVG và cho phép mở lại Mermaid source, nhưng từng thành phần không còn
là shape rời để chỉnh sửa tự do.
